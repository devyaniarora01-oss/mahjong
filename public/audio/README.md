# Table audio

Drop recorded clips here and the game uses them automatically (no code change):

- `calls/<seat>-<pung|chow|kong|mahjong>.mp3` (seat = east/south/west/north) — the claim call-outs
- `tiles/discard.mp3`, `tiles/draw.mp3`, `tiles/claim.mp3` — tile sounds

Until a clip exists, tile sounds are synthesised and call-outs use the browser's built-in voice.
Keep clips short (under a second) and loudness-matched.
